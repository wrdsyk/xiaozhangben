## 新功能
- **从鲨鱼记账导入**：我的 → 备份与恢复 → 从鲨鱼记账导入，选导出的 CSV 明细。导入前先预览；没有对应的分类可以新建，也可以都归入「其他」；重复导入会自动跳过已有的账。
- **自动更新**：打开应用时每天最多检查一次 GitHub 上的新版本，也可以在 我的 → 检查更新 手动检查。下载后会核对签名再交给系统安装。应用只在检查更新时联网，账本数据从不离开手机。
- **4 套新主题**：抹茶、樱粉、深海、墨夜。切换主题改为一次换色、从点击处圆形展开，不再卡顿。

## 统计页重做
- 顶部选 年 / 月 / 周，去掉了「日」。
- 标题可以下拉选择：今年、去年、2024 年…；本月、上月、8 月…；本周、上周、第 44 周…。只列出有账单的时间段。
- 周从周一开始，按 ISO 周编号。年看 1–12 月和月均，月看每天和日均，周看周一到周日。
- 排行榜改为所选时间段里最大的单笔支出。
- 明细和统计左上角的选择器大小统一。

## 定时记账
- 每月可以选多天，每年可以选多个日期。
- 工作日 / 休息日按国务院公布的法定节假日和调休来算（目前收录 2025、2026 年，其他年份按周一至周五）。

## 升级说明
- 从 0.4 及更早版本升级会保留所有数据。这一版需要手动安装一次，之后就能在应用里自动更新了。
